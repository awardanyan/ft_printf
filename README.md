# ft_printf

## 📌 About the Project

ft_printf is a custom implementation of the standard C printf function.

The purpose of this project is to understand:
- Variadic functions
- Format specifiers
- Buffer management
- Low-level output handling

Developed as part of the 42 curriculum.

---

## 🚀 Supported Conversions

- %c — Character
- %s — String
- %p — Pointer
- %d — Decimal (int)
- %i — Integer
- %u — Unsigned integer
- %x — Hexadecimal (lowercase)
- %X — Hexadecimal (uppercase)
- %% — Percent sign

---

## 🛠 Concepts Used

- Variadic arguments (`va_list`)
- Parsing and format handling
- Base conversion
- Memory management
- Write system call

---

## 💡 What I Learned

- How formatted output works internally  
- Working with low-level system calls  
- Handling edge cases and format parsing  
- Writing modular and maintainable C code
